  The rule lives on the step in `lib/flow.ts`, never in the screen.

## Traps — every one of these actually happened

1. **CSS Modules localize `@keyframes`.** `animation: my-anim …` written inside a
   module compiles to a scoped name with no matching keyframes: it resolves to
   nothing and NO animation runs, while `getComputedStyle` still reports a
   duration. Any rule that NAMES an animation must live in `globals.css`. A
   module may safely set `animation-delay`.
2. **The preview pane reports `visibilityState: "hidden"` and freezes rAF and CSS
   transitions** — 0 frames in 400ms. Computed values then sit at the START of a
   transition and jump to the end on a forced reflow, which looks exactly like a
   stuck property. I misdiagnosed this and stripped `Button`'s transitions for
   nothing. **Verify motion via `element.getAnimations()`** — assert the
   animation exists with the expected duration/easing, then scrub
   `animation.currentTime` or call `.finish()`. Never sleep-and-reread.
3. **A Figma stroke does not add to a frame's height; a CSS border does.** With
   `box-sizing: border-box`, a 56-tall row with `padding: 15px` plus a 1px border
   renders 58. Give such rows `min-height` and drop the vertical padding — they
   are flex + centred, so they render identically and land on the Figma height.
4. **A gradient plus a border needs `background-origin: border-box`.**
   `background-origin` defaults to `padding-box` while `background-clip` defaults
   to `border-box`, so the gradient is sized to the padding box but painted into
   the border box — the outermost 1px has no gradient and the drop shadow shows
   through as a thin dark notch at each rounded end. Only affects background
   IMAGES; flat colours are unaffected.
5. **Resolve the ALIAS chain before seeding a paint colour in Figma.** Many
   semantic tokens alias primitives, so a naive `valuesByMode` read returns a
   `VARIABLE_ALIAS`, `x.r` is undefined, and a fallback writes BLACK. The
   inspector still shows the right token name while the thing renders black. This
   bit me twice in one session.
6. **A component edit does not fix an instance carrying a raw override.** Check
   `fills[0].boundVariables` on the instance — `null` means a raw override sits
   on top and will mask your change.
7. **Use the updater form for any toggle**:
   `setAnswer("start", (prev) => toggleMulti(prev ?? [], option))`. Computing from
   the `answers` you read during render uses a snapshot, so two toggles in the
   same tick silently lose the first.
8. **A 44px touch target around a 24px glyph must be offset by HALF the
   difference**, not all of it, or the icon lands 10px inside the content edge.
9. **Figma motion data**: `repeat: Infinity` is a PREVIEW artefact — entrances
   play once. Glyph vectors are often authored pre-rotated and with a negative
   `scaleY`; normalise rotations to END at identity (keeping each track's delta)
   and drop the negative sign, or elements settle crooked or flipped. Scale
   travel distances to the target element.
10. **Don't draw states the App Kit already owns**: loading → `Loading State`
    `257:103`, errors → `Banner` `257:96`, the five interaction states → board
    `04b` `389:200`. Drawing bespoke versions forks the component.
11. **Some Figma values are off-scale in Figma too** (Chip 10/40 padding-height,
    the 60px stack gap on 01). Write them as commented literals rather than
    snapping to a token that would be quietly wrong.

## Open decisions — do not silently resolve

- **Worth knowing about the Button set**: `Style=Secondary, State=Hover` doesn't
  exist, there's no `State=Pressed` for any style, and `button/bg-hover-*` /
  `button/bg-pressed-*` remain unused by the component — ignore those tokens, they
  describe a treatment the button has never used. If a screen needs a secondary
  hover or a pressed state, add the variant in Figma first rather than inventing
  it in CSS. (Pressed elsewhere is `state/pressed-overlay` at 14% with NO
  transform — LUX does not bounce.)
- The orb entrance runs 700ms, longer than `duration/slower` (480), the motion
  board's value for orb and hero entrances. Authored timing was kept.
- Tablet 1024 is deliberately not designed anywhere; below 1024 use the mobile
  composition, at ≥1024 the desktop one.
